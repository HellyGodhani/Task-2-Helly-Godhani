# WRAP & WISH – Gift E-Commerce Platform

## Project Overview

WRAP & WISH is a gift e-commerce platform designed to provide users with a smooth and enjoyable gifting experience. This project focuses on designing the complete user flow from product discovery to order placement.

## Features

* Homepage Navigation
* Gift Categories
* Product Browsing
* Product Details Page
* Wishlist
* Shopping Cart
* Checkout Process
* User Registration
* User Login

## User Flow Covered

1. Homepage
2. Browse Products
3. Product Details
4. Add to Cart
5. Checkout
6. Sign Up
7. Login

## Design Goals

* Easy Navigation
* Simple Shopping Experience
* Reduced Checkout Friction
* User-Friendly Interface

* User Flow Diagram

* UX Documentation
